退会・削除・書き換えの真実

「漏れるのが怖いので、使っていないサービスを退会しまくる」「退会の前に住所や名前をでたらめに書き換える」。SNSで広がっているこの話を、データベースの中で実際に何が起きるかから検証します。

  • 事実には出典を明記
  • 最終更新 2026年10月9日
結論
  • 退会は削除ではありません。退会フラグが立つだけで、データは残る設計が多いです。
  • 書き換え（UPDATE）は「いま見えている1行」にしか効きません。変更履歴、注文の記録、身分証の画像、分析用のコピー、バックアップ、委託先には、元の情報が残ります。
  • 履歴を追記していく設計（INSERT）なら、書き換えると古い住所の行が残り、新しい行が増えるだけです。利用者の側からはどうにもできません。
  • それでも、手間が小さい割に意味はあります。やるなら正しい順番で。そして本命は、法律にもとづく消去請求と、漏れても使えなくする対策です。

あなたのデータは、どこに何個あるか

会員登録すると、あなたの情報は1か所ではなく、いくつもの場所にコピーされます。退会前に住所と名前を書き換えた場合に、それぞれがどうなるかを図にしました（典型的な設計の例です）。

① 会員テーブル書き換えが効く
id氏名住所状態
1024退会者（空）退会

いま画面に出ている情報。UPDATEで上書きされるのはここだけです。

② 変更履歴・監査ログ元の情報が残る
日時項目変更前変更後
2026-10-09住所東京都〇〇区…（空）
2026-10-09氏名山田 花子退会者

変更のたびに行を追記（INSERT）する設計。書き換えるほど「変更前」が記録されます。

③ 注文・配送・請求の記録元の情報が残る
注文日お届け先電話
2024-03-02山田 花子 東京都〇〇区…090-xxxx

注文した時点の住所をそのまま保存します。会計や税務の記録として、何年も残ります。

④ 本人確認書類の画像残る
ファイル登録日
license_1024_front.jpg2021-05-10

会員情報とは別の保管場所にあります。名前を書き換えても画像は消えません。

⑤ 分析用のコピー（データウェアハウス・BIツール）昨日の情報が残る
集計日id住所
2026-10-081024東京都〇〇区…

毎晩コピーされる分析用のデータ。今回Metabaseという分析ツール経由で漏れたのは、まさにこの層です。

⑥ バックアップ・委託先・ログ残る
場所中身
バックアップ数週間〜数年分
メール配信・問い合わせ管理委託先の別システム
アプリのログ入力内容が記録されることも

大和証券、第一興商、シチズン時計の件は、委託先から漏れています。

書き換えが確実に効くのは①だけです。②〜⑥に元の情報が残るかどうかは会社ごとの設計次第で、利用者からは確かめようがありません。だから「消す」だけに頼る作戦は成立しません。

法律で「消せない」データ

法律で一定期間の保存が義務付けられている情報は、あなたが求めても、その期間は消されません。代表例です。

例法律保存期間の目安
中古品の買取・販売の取引記録古物営業法3年
銀行、証券、クレジットカード、暗号資産などの本人確認記録犯罪収益移転防止法取引終了から7年
携帯電話の契約時の本人確認記録携帯電話不正利用防止法契約終了から3年
会計の帳簿や取引の書類法人税法など7年

一方で、法律の義務ではなく会社の方針で保存しているデータもあります。タイムズカーは、免許証の画像を「なりすまし対策やお問い合わせ対応のため」退会後7年間保存していたと説明しています。こうした保存は、消去請求で見直しを求める余地が大きい部分です。

正しい退会の手順

  1. 退会の前にログインし、消せるものを消す
    • 登録したクレジットカード、保存した配送先リストを削除する
    • 任意の項目（電話番号、生年月日、性別、勤務先など）は空にする
    • SNSアカウントとの連携を解除する
    • 本人確認書類を削除する機能があれば使う
  2. メールアドレスは「自分が受け取れる別のアドレス」に変える

    でたらめなアドレスや他人のアドレスにしてはいけません。理由は2つあります。

    • 漏えいの通知が届かなくなります。タイムズカーでは、退会者の連絡先が古く、個別の通知に手間取っています。
    • 他人のアドレスにすると、その人がパスワード再設定であなたの残りの情報を見られる場合があります。

    サービスごとに作れる転送用アドレス（エイリアス）が最適です。エイリアスの作り方

  3. 氏名や住所をでたらめに書き換えるのは慎重に
    • 利用規約で虚偽の登録が禁止されていることがあります
    • でたらめの住所や電話番号が、実在する他人のものに当たることがあります
    • 本人確認済みの項目は変更できないか、変更の記録が残ります

    やるなら「任意の項目を空にする」を中心にし、必須項目は明らかに架空と分かる値にとどめるのが安全です。

  4. 退会する

    退会を完了した画面やメールを、日付が分かる形で保存しておきます。

  5. 消去を請求する（法律上の権利）

    個人情報保護法第35条第5項により、次の場合には、会社に保有個人データの利用停止や消去を請求できます。

    • 会社があなたのデータを利用する必要がなくなった場合（退会後など）
    • あなたのデータについて漏えいなどの事態が起きた場合
    • そのほか、扱い方によってあなたの権利や正当な利益が害されるおそれがある場合

    会社は、請求に理由があれば遅滞なく対応し、結果を本人に通知しなければなりません（同条第6項・第7項）。請求先は、各社のプライバシーポリシーにある「開示等の請求」の窓口です。下で文面を作れます。

  6. 回答を記録し、応じてもらえなければ相談する

    回答がない、理由なく断られた場合は、個人情報保護委員会の相談ダイヤルに相談できます。

消去請求の文面を作る

入力した内容は、この端末の中だけで文章に組み立てます。どこにも送信されません。会社の窓口に専用の書式がある場合は、そちらを優先してください。

送る前に
  • 本人確認のため、会社から追加の書類を求められることがあります。その案内が本物かどうかは、会社の公式サイトで確かめてください。
  • 開示の請求には、手数料がかかる場合があります（法第38条）。
  • 消去の請求をすると、そのサービスの利用履歴やポイントは戻りません。

どのサービスから手を付けるか

漏れたときの被害が大きい順に並べました。時間は限られているので、上から片付けます。

  1. 本人確認書類を提出したサービス：カーシェア、レンタカー、フリマ、中古品の買取、マッチングアプリ（年齢確認）、暗号資産、証券、後払い、転職サイト、ホテル予約（パスポート）
  2. 住所、生年月日、電話番号を登録したサービス：通販、会員アプリ、ポイントカード、アンケートサイト
  3. カード情報を登録したサービス：まずカードの登録だけでも削除する
  4. メールアドレスだけのサービス：エイリアスに変えるか、退会する

使ったサービスを思い出す方法

  • メールで「ご登録ありがとうございます」「会員登録完了」「本人確認」「ご本人様確認書類」を検索する
  • スマホのパスワード管理アプリに保存された一覧を見る
  • 財布の中のポイントカードと、スマホのアプリ一覧を見る
