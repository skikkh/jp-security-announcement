運転免許証・身分証の画像が漏れたら

タイムズカーでは、約160万アカウントで運転免許証などの本人確認書類の画像が漏れ、退会者も含まれていました。顔写真と生年月日は変えられません。漏れた情報の種類と、対策が届く範囲を確かめて手を打ちます。

まず、自分が対象か確かめる

  • 対象者には各社から個別に通知が届きます。ただし、通知を装った詐欺メールも出ます。メールのリンクは使わず、公式サイトを自分で開いて確認してください。
  • 退会済みでも対象になることがあります。タイムズカーは、退会後も氏名・住所・生年月日を税法などにもとづき7年間、免許証の情報と画像をなりすまし対策や問い合わせ対応のため7年間保管していたと説明しています。
  • 退会時のメールアドレスが使えなくなっている人には、公式サイトの問い合わせフォームから今の連絡先を届け出る方法が案内されています。
  • タイムズカーの場合、漏えいした情報は氏名、住所、生年月日、電話番号、メールアドレス、運転免許情報、本人確認書類の画像（免許証、住所確認書類、学生証、家族確認書類）、パスワード（復元できない形式）などです。クレジットカード情報は保有していないとしています。

出典：タイムズカーWebサイトへの不正アクセスに関するご質問と回答（2026年10月6日更新）

漏れた画像で、何ができてしまうか

できてしまうこと難しいこと
流出画像や記載事項を偽造書類の材料に使うおそれがあります。券面の目視だけに頼る確認では見抜けない場合があります。ただし、画像だけで契約やSIM再発行が必ず通るわけではなく、各社・各手続の本人確認によります。 真正なICチップや電子証明書を検証する本人確認。券面画像だけでは代用できません。ただし、IC読み取り以外の手続や追加の情報が狙われる可能性は残ります。
本物の番号や写真を見せて信用させる。「あなたの免許証が犯罪に使われた」と警察を名乗る詐欺の小道具になります。 マイナンバーカードの電子証明書を使う本人確認（公的個人認証）。カードの実物と暗証番号が必要です。
名簿として売買され、ほかの漏えい情報と結び付けられる。 書類画像と、その場で撮影した容貌を照合する本人確認。書類画像だけでは足りません。ただし、照合の成否やなりすまし耐性は実装により異なり、万能ではありません。
危険なのは「目で見るだけの確認」と「信用させる道具」

画像による確認とICチップを使う確認は、求められる証拠が異なります。制度の移行後も、すべての事業者・手続が同じ方法になるわけではありません。なお、運転免許証の画像には顔写真・免許証番号等、マイナンバーカードの表面画像には顔写真等、裏面画像には12桁の個人番号、旅券の画像には顔写真・旅券番号等が含まれます。番号だけが漏れた場合と書類の画像が漏れた場合では、悪用の材料が異なります。マイナンバーだけで行政手続はできません。タイムズカーの公表対象は免許証画像等であり、マイナンバーカードや旅券の画像が漏れたとは公表されていません。

  • 携帯電話の非対面契約：顔と写真付き本人確認書類の画像を送る方法等は、2026年4月の改正で廃止されました。書類原本の送付等、存続する方法もあります。
  • 携帯電話の対面契約：写真付き本人確認書類の提示にICチップ読み取りを原則加える改正は、2027年4月施行予定です。契約時の制度改正が、機種変更・SIM再発行の全手続にそのまま当てはまるとは限りません。
  • 金融機関等の犯収法上の取引時確認：書類画像と容貌画像を用いる「ホ方式」等は、2027年4月1日に廃止されます。対面の写真付き書類の提示には、ICチップ読み取りが加わります。対象となる取引・確認方法は法令で確認してください。

金融庁は2026年10月9日、画像や顔写真の不自然な点を確認し、2027年4月1日の施行を待たず、ICチップ読取へ可及的速やかに移行するよう金融機関等へ要請しています。金融庁の発表

制度上の期限と各社の実装状況は分けて確認してください。漏れた券面画像の悪用可能性が、施行日に一律に消えるわけではありません。

状況に応じてやること

以下の掲載順は効果の順位ではありません。実際に漏れた項目、すでに使っている認証方法、見覚えのない請求の有無に応じて選んでください。

0 / 6 完了
  1. やり方
    • 携帯会社のアカウント（dアカウント、au ID、My SoftBank、楽天IDなど）のパスワードを固有のものにし、2段階認証をオンにする
    • 契約時の4桁の暗証番号が生年月日などなら、変更する
    • 銀行、証券、決済アプリが対応していれば、SMSに依存しないパスキー等を設定する。生体認証は端末を解除する方法の一つで、それだけで全取引が安全になるわけではない
    • 突然「圏外」「SIMなし」になったら、別の電話からすぐ携帯会社に連絡する

    アカウントのパスワード変更やSMSを使わない認証はオンライン側の被害を減らしますが、店頭での偽造書類を使ったSIM再発行まで必ず防ぐものではありません。追加の保護や再発行時の確認方法は契約先に確認してください。

  2. しくみ・申し込み方

    クレジットカードやローンの審査で加盟会社が信用情報を照会した際、本人申告が参考情報として表示されます。加盟会社の判断を拘束せず、慎重な確認や悪用防止を保証する制度ではありません。

    機関主な利用会社申し込み方
    CICクレジットカード、信販紛失・盗難・名義の悪用に関する申告はインターネットか郵送。インターネット申込にはCICに登録された電話番号からの受付番号取得が必要。画像流出で名義悪用が心配な場合の例も公式サイトに掲載
    JICC（日本信用情報機構）消費者金融、クレジット満15歳以上の本人が申し込める。現物は手元にあり画像等が流出した場合は「名義の悪用防止」。登録日から5年間
    全国銀行個人信用情報センター（KSC）銀行、銀行系カードインターネット（マイナンバーカードとNFC対応スマホが必要）か郵送。手数料500円。本人確認書類の漏えい等による名義悪用の可能性が対象。通常の商取引で画像を送信しただけなら原則受付対象外。今回の通知がある場合の該当性は窓口で確認する
    • 本人申告の登録期間はCIC・JICC・全国銀行個人信用情報センターの公式案内でいずれも5年以内または登録日から5年です。インターネット・アプリでの登録手数料は順に1,000円・700円・500円（2026年10月確認）。郵送費用と本人確認方法は異なるので申込前に確認してください。

    出典：CICの本人申告、JICCの本人申告、全国銀行個人信用情報センターの本人申告

    本人申告の限界
    • 審査で信用情報を照会しない契約には効きません。全国銀行個人信用情報センターへの本人申告は、預金口座の開設時には照会されません。
    • 悪用を確実に止めるものではなく、補償もありません。
    • あなた自身が新しくカードなどを申し込むときも、確認に時間がかかることがあります。
  3. やり方
    • 各機関の公式サイトから本人開示を申し込む。CICのインターネット開示は500円、JICCのスマホアプリ開示は700円、全国銀行個人信用情報センターのインターネット開示は800円（2026年10月確認）。郵送の費用・本人確認方法は別です。開示の推奨頻度に一律の根拠はありません
    • 知らない会社からの照会記録や、覚えのない契約がないか見る。照会・申込情報には保有期間があり、CIC・JICCの申込情報は照会日から6か月以内。全国銀行個人信用情報センターの会員照会記録は、本人開示で1年以内、会員への提供は6か月以内です。期間を過ぎた照会は開示で見つけられない場合があります
    • 見つけたら、その会社と警察に連絡する。連絡先は、自分で調べた公式の番号を使う

    出典：CICの本人開示、JICCの本人開示、全国銀行個人信用情報センターの本人開示、CICの登録期間、JICCの登録期間、全国銀行個人信用情報センターの登録期間

  4. 典型的な流れ

    「あなたの免許証が詐欺グループの口座開設に使われた」「あなたにも逮捕状が出ている」と電話があり、LINEやビデオ通話に誘導され、「捜査のため」と口座やお金の確認を求められます。漏れた免許証の情報で、話に本物らしさが加わります。

    • 警察が電話でお金や口座の確認を求めることはありません
    • LINEやビデオ通話に移るよう言われたら、その時点で詐欺と判断して切る
    • 不安なら、自分で調べた警察署の代表番号か、警察相談専用電話 #9110 にかけて確かめる

免許証の再交付は効くのか

画像流出だけで再交付できるかは、住所地の都道府県警察の受付条件によります。通常の再交付には紛失、盗難、汚損、破損、表示内容・写真の変更などの要件があります。紛失・盗難を装って申請しないでください。

再交付で変わるもの変わらないもの
新しく撮影する顔写真、交付日など。免許証番号の末尾が変わる場合がある 氏名、生年月日、住所、本人の顔。流出済みの画像も回収できない
再交付だけでは、なりすましを止められません

再交付は流出済みの顔写真や氏名等を消しません。番号の末尾等が変わっても、相手先が旧券面の有効性を確認しない目視確認では、不正利用を防げるとは限りません。効果を一律に評価できる資料は見つかっていません。

再交付を考える場合は、住所地の都道府県警察の公式案内で、画像流出が受付理由になるか、必要書類と手数料を確認してください。

出典：警視庁「再交付・再記録手続」、警視庁「運転免許証の不正取得」。他道府県の画像流出に伴う特例は住所地の警察へ確認してください。

これから身分証を出すときの注意

  • コピーや画像を求められたら、理由と保存期間を聞く。本当に必要か、何年保存するのか、退会したら消すのかを確かめます。
  • 住所の確認だけが目的なら、不要な部分を隠せないか聞く。免許証番号などを隠して出せる場合があります。
  • メールやアップロードで画像を送るなら、提出先と日付の書き込みを認めるか確認する。認められる場合は「〇〇社 提出用 〇年〇月」のように記すと、転用を難しくし、流出経路を調べる手掛かりになります。必要な記載や顔写真を隠さず、提出先の指定に従ってください。アプリのカメラで撮る方式では使えません。
  • 選べるなら、マイナンバーカードの公的個人認証（電子証明書）を使う。券面画像を渡さずに本人確認できる場合があります。電子証明書とカードの実物・暗証番号を用いる方式です。暗証番号は誰にも教えないでください。
