2026年10月版 市民のための自衛ガイド

あなたの名前・住所・電話番号は、
もう漏れている前提で動いてください。

それでも、被害を抑えるためにできることがあります。漏れた情報は取り戻せませんが、悪用される経路を減らし、早く気づくことはできます。このサイトは、漏れた項目と現在の状況に合わせて対策を選ぶためのガイドです。

状況に合わせて、ここから

  • 覚えのない支払い・送金・取引がある被害を止めるために、まず連絡する銀行・証券・カード会社など、利用した事業者の公式窓口へ。パスワード変更より連絡を急ぐ場合があります。
  • 利用したサービスから通知が来た自分が対象か、何の情報が漏れたかを確認会社名・サービス名で探し、公式発表と自分への通知を確認。通知のリンクから手続きせず、公式サイトを自分で開きます。
  • 漏れた情報に合わせて対策したい自分に必要な対策を選ぶ身分証、パスワード、住所など、通知で確認した項目を選べます。まだ分からない場合も、確認から始められます。

いま何が起きているか

マクニカが定義した国内Webシステムの事案では、2026年7月以降の公表が増えています。同社は、弱いシステムを広く探す攻撃の可能性が高いと分析しています。ただし、公表情報だけでは侵入原因が分からない事案も多く、すべてが同じ手口と確認されたわけではありません。

  • 119件マクニカが定義した国内Webシステムの漏えい事案の2026年公表数（10月6日時点）。同じ基準で2025年は84件。国内の全漏えい件数ではありません
  • 約1,079万件焼肉きんぐ公式アプリの会員情報（10月5日公表）
  • 約660万件タイムズカーのアカウント情報。退会者を含みます（9月28日公表）
  • 約160万件そのうち、運転免許証などの本人確認書類の画像が漏れたアカウント

このほか、第一興商（約872万件のおそれ）、ブックオフ（最大約643万件の可能性）、ローソンID（約215万件）、佐川急便やヤマト運輸の関連サービスの情報など、生活に身近なサービスで公表が続いています。主な漏えい事案の一覧で、あなたが使っていたサービスを確認できます。

出典：マクニカ セキュリティ研究センター（2026年10月7日）、JPCERT/CC 注意喚起（10月8日）、各社の発表。件数は公表時点の数字で、今後変わることがあります。

パスワード以外の情報も漏えいしています

漏れた項目は事案ごとに違います。氏名・生年月日・顔写真はパスワードのように変えられず、住所も簡単には変えられません。本人確認に使われ得る情報だけを秘密の証拠にせず、悪用される道筋に合わせて対策します。詳しくはなぜこの対策なのかで説明しています。

覚えておく3つの原則

  1. 届いた連絡からは動かない

    メール、SMS、電話、郵便、訪問。相手が何を知っていても、そこから手続きをしません。一度閉じて、公式アプリ、ブックマーク、カード裏面の番号など、前から知っている入口から自分で確かめます。

  2. 「知っている」は本物の証拠ではない

    名前、住所、生年月日、使っているサービス、最近の注文や配送。いまは詐欺師も知っています。逆に、暗証番号や「秘密の質問」に生年月日などを使っているなら、今日変えてください。

  3. 消去の確認と、悪用を減らす対策を併せる

    事業者に残る情報の消去は、保存目的や法令によって扱いが変わります。あわせて、パスワードの使い回しをなくす、対応サービスでパスキーを使う、銀行振込の限度額や利用通知を見直すなど、被害の種類に合う対策を進めます。

被害が確認されていない人の点検（今日の30分）

被害が進行中なら、共通の点検より先に対応してください

不正な支払い・送金や証券取引、カード番号やパスワードの流出、突然の「圏外」などがあれば、被害時の初動を優先してください。金融機関に関わるときは連絡を急ぎます。漏れた項目が分かる場合は自分専用の対策を作れます。

以下は被害が確認されていない人向けの共通の点検です。必要性と順番は、漏れた情報や利用中のサービスによって変わります。チェックを入れると、この端末に記録されます。

0 / 6 完了
  1. なぜ・やり方

    多くのサービスの「パスワード再設定」はメールに届きます。メールを取られると、ほかのアカウントも狙われます。メールは多くのアカウントの合鍵です。

    • Gmail、iCloud、Yahoo!メール、キャリアメールなど、普段使うメールのパスワードが長く、推測しにくく、ほかで使っていないものか確認する。流出・使い回し・不審なログインがあれば変える
    • 設定の「セキュリティ」から、パスキーか2段階認証をオンにする
    • 再設定用の電話番号と予備のメールアドレスが、今も自分のものか確認する。不審なログインがあればログイン中の端末や転送設定も点検する
  2. なぜ・やり方

    偽造した身分証で携帯ショップに行き、あなたの電話番号を別のSIMに移す「SIM乗っ取り」が実際に起きています。番号を取られると、SMSで届く認証コードが全部相手に届きます。漏れた免許証の画像は、偽造の材料になり得ます。

    • dアカウント、au ID、My SoftBank、楽天IDなど、携帯会社のアカウントのパスワードを固有のものにし、2段階認証をオンにする
    • 契約時に決めた4桁の暗証番号が、生年月日や「1234」なら変更する
    • 突然「圏外」や「SIMなし」になったら、別の電話からすぐ携帯会社に連絡する

    携帯電話の守り方を詳しく

  3. なぜ・やり方

    振込限度額は、ネットバンキングを使う人が銀行振込による被害額を抑えるための設定です。カード決済やなりすまし契約の上限にはなりません。銀行によっては、限度額を上げるときに追加の確認や時間がかかります。

    • 銀行のアプリやサイトで、1日の振込限度額を、普段の振込に必要な最小限まで下げる
    • ログイン、振込、出金のお知らせ（メールやアプリの通知）をオンにする
    • 使っていない口座は、解約も検討する
  4. なぜ・やり方

    不正利用は、早く気づくほど止めやすくなります。多くのカードは、不正利用の補償を受けられる期間に期限があります。

    • カード会社の公式アプリで、利用通知を「すべての利用」でオンにする
    • PayPayなどのスマホ決済は、利用通知をオンにし、銀行口座からの自動チャージの設定を見直す
    • 毎月の明細で、少額の見覚えのない請求も確認する。少額の請求は、カードが使えるかの「試し打ち」のことがあります
  5. なぜ・やり方

    漏れた情報には、住所や家族の情報が含まれることがあります。息子、孫、警察、役所を名乗る電話は、以前よりずっと本物らしくなります。

    • 家族だけが知っている合言葉を決める。誕生日、住所、ペットの名前など、漏れうる情報は使わない
    • 「お金、カード、暗証番号、口座の話が出たら、一度切って、自分が知っている番号にかけ直す」と家族全員で決める
    • 高齢の家族には、家族を守るページのカードを印刷して渡す
  6. なぜ・やり方

    パスワードが流出した場合、保存方法によっても危険は変わります。元に戻せない形（ハッシュ化）で保存されていても、短いものやよくあるものは推測され得ます。メールアドレスだけが漏れた場合とは分けて考えます。

    • 漏えいした項目にパスワードが含まれるか、サービスの公式発表で確認する
    • パスワードが漏れた、または使い回していた場合は、同じ・似たパスワードのサービスを、メール、銀行・証券、買い物、SNSの順に変える
    • 覚えきれない場合は、スマホに標準で入っているパスワード管理（iPhoneの「パスワード」アプリ、Googleパスワードマネージャー）に保存させる

今週中にやること

  • 使い回しを根絶パスワード管理を使い、長く、ランダムで別々にする1つ漏れても、ほかへの悪用を防ぎやすくなります。
  • 偽サイトに強いログイン大事なサービスでパスキーを使うSMSも認証なしより安全です。パスキーを設定する際は復旧手段も確認します。
  • 免許証などが漏れた人信用情報機関への本人申告を検討するカードやローンの審査で参考にされる制度です。機関ごとの受付条件と限界を確かめてください。
  • SMS詐欺を減らす携帯会社の迷惑SMSフィルタをオンにする多くは無料です。怪しいSMSの一部を受信前に止められます。
  • 固定電話がある家国際電話の発着信を無料で止める詐欺電話には国際電話番号がよく使われています。
  • 将来の漏えいを減らす使っていないサービスの退会と保存データを確認する退会後も一部の情報が残る場合があります。条件に合えば、利用停止や消去を請求できます。

いま、こんな状況なら

  • 通知が来た「漏えいのお知らせ」が届いた本物か確かめる方法と、届いた後にやること。
  • 身分証の画像・番号免許証・身分証の画像が漏れたできる対策と、その効果・受付条件の限界を確認します。
  • データを消したい退会すれば消える？書き換えは効く？データベースの中で実際に何が起きるかを図で説明します。
  • 怪しい連絡メール・SMS・電話が来た漏えいに便乗した詐欺の典型と、見分けずに防ぐ方法。
  • 家族が心配高齢の親を守りたい印刷して冷蔵庫に貼れる「わが家のルール」付き。
  • 被害に遭った入力した・払ってしまった順番どおりに動けば、被害を止められることがあります。

漏れた情報に合わせて対策を選ぶ

デジタル大臣は10月6日、国民に「パスワードの使い回しをやめる」「多要素認証を使う」「不審なメールやSMSに注意する」の3つを呼びかけました。公式サイト・公式アプリからアクセスすることも案内しています。このサイトでは、電話・郵便・訪問も含め、漏れた情報に応じた確認の手順を整理します。

  • 漏れた情報は、パスワードだけではありません。住所、生年月日、免許証の画像は、パスワードを変えても守れません。
  • SMSの認証コードは万全ではありません。認証なしより安全ですが、電話番号の乗っ取りや、偽サイトでコードをその場で横取りする手口に弱いからです。
  • 漏れた情報を使った詐欺は、不審に見えません。見分ける力に頼らず、「届いた連絡からは動かない」という行動のルールで防ぎます。
