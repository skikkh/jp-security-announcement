2026年10月 緊急ガイド

あなたの名前・住所・電話番号は、
もう漏れている前提で動いてください。

それでも、被害は防げます。漏れた情報は取り戻せません。でも、漏れた情報を「お金に変えられない情報」にすることはできます。このサイトは、そのための手順を効果の大きい順に並べたものです。

今日の30分でやること 漏れた情報から、自分専用の対策を作る

いま何が起きているか

2026年7月ごろから、企業のWebサイトやスマホアプリから個人情報が盗まれる事件が急増しています。特定の会社を狙ったものではなく、弱いところがあるシステムを手当たり次第に探して入り込む攻撃だと分析されています。

  • 119件2026年に公表された、Webシステムからの個人情報の流出（10月6日時点）。2025年は1年間で84件でした
  • 約1,079万件焼肉きんぐ公式アプリの会員情報（10月5日公表）
  • 約660万件タイムズカーのアカウント情報。退会者を含みます（9月28日公表）
  • 約160万件そのうち、運転免許証などの本人確認書類の画像が漏れたアカウント

このほか、第一興商（約872万件のおそれ）、ブックオフ（最大約643万件の可能性）、ローソンID（約215万件）、佐川急便やヤマト運輸の関連サービスの情報など、生活に身近なサービスで公表が続いています。主な漏えい事案の一覧で、あなたが使っていたサービスを確認できます。

出典：マクニカ セキュリティ研究センター（2026年10月7日）、JPCERT/CC 注意喚起（10月8日）、各社の発表。件数は公表時点の数字で、今後変わることがあります。

今回漏れたのは、パスワードより「あなたが本人である証拠」です

パスワードは変えられます。でも、氏名・住所・生年月日・顔写真は変えられません。これまで「本人確認」に使われてきた情報が、もう秘密ではなくなりました。だから、守る対象を「情報そのもの」から「情報がお金に変わる道筋」に切り替えます。詳しくはなぜこの対策なのかで説明しています。

覚えておく3つの原則

  1. 届いた連絡からは動かない

    メール、SMS、電話、郵便、訪問。相手が何を知っていても、そこから手続きをしません。一度閉じて、公式アプリ、ブックマーク、カード裏面の番号など、前から知っている入口から自分で確かめます。

  2. 「知っている」は本物の証拠ではない

    名前、住所、生年月日、使っているサービス、最近の注文や配送。いまは詐欺師も知っています。逆に、暗証番号や「秘密の質問」に生年月日などを使っているなら、今日変えてください。

  3. 消すより、使えなくする

    企業に残ったデータは、個人では消しきれません。パスワードを使い回さない、ログインはパスキーにする、振込限度額を下げる、通知をオンにする。漏れてもお金に届かない状態を作ります。

今日の30分でやること

効果が大きい順に並べています。チェックを入れると、この端末に記録されます。

0 / 6 完了
  1. なぜ・やり方

    ほぼすべてのサービスの「パスワード再設定」はメールに届きます。メールを取られると、ほかのアカウントを次々に取られます。メールは全アカウントの合鍵です。

    • Gmail、iCloud、Yahoo!メール、キャリアメールなど、普段使うメールのパスワードを、ほかで使っていない長いものに変える
    • 設定の「セキュリティ」から、パスキーか2段階認証をオンにする
    • 再設定用の電話番号と予備のメールアドレスが、今も自分のものか確認する
  2. なぜ・やり方

    偽造した身分証で携帯ショップに行き、あなたの電話番号を別のSIMに移す「SIM乗っ取り」が実際に起きています。番号を取られると、SMSで届く認証コードが全部相手に届きます。漏れた免許証の画像は、偽造の材料になり得ます。

    • dアカウント、au ID、My SoftBank、楽天IDなど、携帯会社のアカウントのパスワードを固有のものにし、2段階認証をオンにする
    • 契約時に決めた4桁の暗証番号が、生年月日や「1234」なら変更する
    • 突然「圏外」や「SIMなし」になったら、別の電話からすぐ携帯会社に連絡する

    携帯電話の守り方を詳しく

  3. なぜ・やり方

    どんな対策も破られることがあります。破られたときの被害額に上限をつけるのが、最後の防壁です。銀行によっては、限度額を上げるときに追加の確認や時間がかかり、攻撃者の手間も増えます。

    • 銀行のアプリやサイトで、1日の振込限度額を、普段の振込に必要な最小限まで下げる
    • ログイン、振込、出金のお知らせ（メールやアプリの通知）をオンにする
    • 使っていない口座は、解約も検討する
  4. なぜ・やり方

    不正利用は、早く気づくほど止めやすくなります。多くのカードは、不正利用の補償を受けられる期間に期限があります。

    • カード会社の公式アプリで、利用通知を「すべての利用」でオンにする
    • PayPayなどのスマホ決済は、利用通知をオンにし、銀行口座からの自動チャージの設定を見直す
    • 毎月の明細で、少額の見覚えのない請求も確認する。少額の請求は、カードが使えるかの「試し打ち」のことがあります
  5. なぜ・やり方

    漏れた情報には、住所や家族の情報が含まれることがあります。息子、孫、警察、役所を名乗る電話は、以前よりずっと本物らしくなります。

    • 家族だけが知っている合言葉を決める。誕生日、住所、ペットの名前など、漏れうる情報は使わない
    • 「お金、カード、暗証番号、口座の話が出たら、一度切って、自分が知っている番号にかけ直す」と家族全員で決める
    • 高齢の家族には、家族を守るページのカードを印刷して渡す
  6. なぜ・やり方

    パスワードが暗号化されて保存されていても、短いものやよくあるものは解読されることがあります。解読されたパスワードは、ほかのサービスへのログインに自動で試されます。

    • 漏えいが公表されたサービスで使っていたパスワードを思い出す
    • 同じ、または似たパスワードを使っているサービスを、メール、銀行・証券、買い物、SNSの順に変える
    • 覚えきれない場合は、スマホに標準で入っているパスワード管理（iPhoneの「パスワード」アプリ、Googleパスワードマネージャー）に保存させる

今週中にやること

  • 使い回しを根絶パスワード管理を使い、全部を別々にする1つ漏れても、ほかに広がらなくなります。
  • 偽サイトに強いログイン大事なサービスをパスキーに切り替えるSMSの認証コードは横取りされることがあります。パスキーは偽サイトでは使えません。
  • 免許証などが漏れた人信用情報機関に「本人申告」をするあなたの名前でのカードやローンの申し込みに、注意の目印を付けてもらえます。
  • SMS詐欺を減らす携帯会社の迷惑SMSフィルタをオンにする多くは無料です。危険なリンク付きのSMSを受信前に止めます。
  • 固定電話がある家国際電話の発着信を無料で止める詐欺電話には国際電話番号がよく使われています。
  • 将来の漏えいを減らす使っていないサービスを洗い出し、退会と消去請求退会しただけではデータは消えません。法律にもとづく消去請求の文面を作れます。

いま、こんな状況なら

  • 通知が来た「漏えいのお知らせ」が届いた本物か確かめる方法と、届いた後にやること。
  • いちばん深刻免許証・身分証の画像が漏れた何ができてしまい、何はできないか。効く順の対策。
  • データを消したい退会すれば消える？書き換えは効く？データベースの中で実際に何が起きるかを図で説明します。
  • 怪しい連絡メール・SMS・電話が来た漏えいに便乗した詐欺の典型と、見分けずに防ぐ方法。
  • 家族が心配高齢の親を守りたい印刷して冷蔵庫に貼れる「わが家のルール」付き。
  • 被害に遭った入力した・払ってしまった順番どおりに動けば、被害を止められることがあります。

国の呼びかけだけでは足りない理由

デジタル大臣は10月6日、国民に「パスワードの使い回しをやめる」「多要素認証を使う」「不審なメールやSNSに注意する」の3つを呼びかけました。どれも正しい対策です。ただ、今回の漏えいの性質を考えると、それだけでは防げない被害があります。

  • 漏れた情報の多くは、パスワードではありません。住所、生年月日、免許証の画像は、パスワードを変えても守れません。
  • SMSの認証コードは万全ではありません。電話番号の乗っ取りや、偽サイトでコードをその場で横取りする手口に弱いからです。
  • 漏れた情報を使った詐欺は、不審に見えません。見分ける力に頼らず、「届いた連絡からは動かない」という行動のルールで防ぎます。

漏れた後の守り方

個人が運営する非公式の情報サイトです。政府・企業・各機関の公式発表を優先してください。事実関係には出典を付けています。最終更新：2026年10月9日。

このサイトは外部のスクリプト、アクセス解析、広告、Cookieを一切使っていません。チェックの記録は、あなたの端末の中にだけ保存されます。
