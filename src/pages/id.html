運転免許証・身分証の画像が漏れたら

タイムズカーでは、約160万アカウントで運転免許証などの本人確認書類の画像が漏れ、退会者も含まれていました。顔写真と生年月日は変えられません。だからこそ、何ができてしまい、何はできないのかを整理し、効く順に手を打ちます。

まず、自分が対象か確かめる

  • 対象者には各社から個別に通知が届きます。ただし、通知を装った詐欺メールも出ます。メールのリンクは使わず、公式サイトを自分で開いて確認してください。
  • 退会済みでも対象になることがあります。タイムズカーは、退会後も氏名・住所・生年月日を税法などにもとづき7年間、免許証の情報と画像をなりすまし対策や問い合わせ対応のため7年間保管していたと説明しています。
  • 退会時のメールアドレスが使えなくなっている人には、公式サイトの問い合わせフォームから今の連絡先を届け出る方法が案内されています。
  • タイムズカーの場合、漏えいした情報は氏名、住所、生年月日、電話番号、メールアドレス、運転免許情報、本人確認書類の画像（免許証、住所確認書類、学生証、家族確認書類）、パスワード（復元できない形式）などです。クレジットカード情報は保有していないとしています。

出典：タイムズカーWebサイトへの不正アクセスに関するご質問と回答（2026年10月6日更新）

漏れた画像で、何ができてしまうか

できてしまうこと難しいこと
偽造の身分証を作り、券面を目で見るだけの確認を通る。携帯ショップでの機種変更やSIMの再発行もその一つです。2024年には、偽造マイナンバーカードで地方議員の携帯電話が乗っ取られ、スマホ決済で高額な腕時計を買われる事件が起きました。 ICチップを読み取る本人確認。偽造した券面には正しいICチップがありません。免許証のICチップの読み取りには暗証番号も必要です。
本物の番号や写真を見せて信用させる。「あなたの免許証が犯罪に使われた」と警察を名乗る詐欺の小道具になります。 マイナンバーカードの電子証明書を使う本人確認（公的個人認証）。カードの実物と暗証番号が必要です。
名簿として売買され、ほかの漏えい情報と結び付けられる。 その場で撮影した顔と書類を照合するオンライン本人確認。画像だけでは通りにくい仕組みです。ただし、絶対ではないと事業者側も説明しています。
危険なのは「目で見るだけの確認」と「信用させる道具」

携帯電話の店頭契約でICチップの読み取りが義務になるのは2027年4月1日からです。それまでは券面を目で見る確認も認められています。また、身分証の画像と顔写真を組み合わせるオンライン本人確認（いわゆる「ホ方式」）は、2027年4月1日に廃止される予定です。つまり今後1年半ほどは、画像の流出が悪用されやすい期間が続きます。

やること（効く順）

0 / 6 完了
  1. やり方
    • 携帯会社のアカウント（dアカウント、au ID、My SoftBank、楽天IDなど）のパスワードを固有のものにし、2段階認証をオンにする
    • 契約時の4桁の暗証番号が生年月日などなら、変更する
    • 銀行、証券、決済アプリのログインを、SMS認証からパスキーや生体認証に切り替えられるなら切り替える
    • 突然「圏外」「SIMなし」になったら、別の電話からすぐ携帯会社に連絡する
  2. しくみ・申し込み方

    クレジットカードやローンの審査で、会社があなたの信用情報を照会したときに「本人確認に注意してください」という申告内容が表示されます。会社は、より慎重に本人確認をします。

    機関主な利用会社申し込み方
    CICクレジットカード、信販紛失・盗難・名義の悪用に関する申告は、インターネットか郵送
    JICC（日本信用情報機構）消費者金融、クレジット公式サイトから申し込み。免許証の現物は手元にあり、画像だけ漏れた場合は「名義の悪用防止」を選ぶ。登録は5年間
    全国銀行個人信用情報センター（KSC）銀行、銀行系カードインターネット（マイナンバーカードとNFC対応スマホが必要）か郵送。手数料500円。通常の取引で画像を送っただけの場合は原則受け付けないとしているため、漏えいの通知を受けた場合の扱いを確認してから申し込む
    • 手数料や登録期間は機関ごとに違います。申し込む前に、上の公式サイトで確認してください。
    • 9月末から申し込みが集中し、各機関で手続きに通常より日数がかかっています。ネットがつながりにくい場合は、郵送も選べます。
    本人申告の限界
    • 審査で信用情報を照会しない契約には効きません。
    • 悪用を確実に止めるものではなく、補償もありません。
    • あなた自身が新しくカードなどを申し込むときも、確認に時間がかかることがあります。
  3. やり方
    • 各機関の公式サイトから、自分の信用情報の開示を申し込む（スマホから申し込める機関もあります）
    • 知らない会社からの照会記録や、覚えのない契約がないか見る
    • 見つけたら、その会社と警察に連絡する。連絡先は、自分で調べた公式の番号を使う
  4. 典型的な流れ

    「あなたの免許証が詐欺グループの口座開設に使われた」「あなたにも逮捕状が出ている」と電話があり、LINEやビデオ通話に誘導され、「捜査のため」と口座やお金の確認を求められます。漏れた免許証の情報で、話に本物らしさが加わります。

    • 警察が電話でお金や口座の確認を求めることはありません
    • LINEやビデオ通話に移るよう言われたら、その時点で詐欺と判断して切る
    • 不安なら、自分で調べた警察署の代表番号か、警察相談専用電話 #9110 にかけて確かめる

    • 身に覚えのないクレジットカード、請求書、督促状、契約書類、「ご契約ありがとうございます」というSMS
    • 見つけたら、書類に書かれた番号ではなく、会社の公式サイトで調べた番号に連絡する

免許証の再交付は効くのか

タイムズカーの漏えいを受けて、広島、山口、和歌山、香川、石川などの公安委員会が、希望者への運転免許証の再交付を特例で受け付けていると報じられています。対応、条件、手数料は都道府県ごとに違います。

再交付で変わるもの変わらないもの
顔写真。免許証番号の末尾1桁（再交付の回数を表す数字） 氏名、生年月日、住所。そして、あなたの顔そのもの
優先度は、本人申告と電話番号の守りより下です

古い券面をもとにした偽造品は、番号を照会すれば見抜ける可能性があります。ただ、お店が免許証番号を照会する仕組みは一般的ではありません。偽造品は券面を目で見るだけの確認を狙うので、番号の末尾が変わっても見抜かれにくいのです。警察関係者からも「再交付しても安心できるものではない」との声が報じられています。

不安が大きく、住所地の都道府県が受け付けているなら、選んでよい対策です。まず住所地の運転免許センターか警察署に、特例の有無と条件を確認してください。

出典：KSB瀬戸内海放送（香川県）、NHK（石川県）、山口県警の対応（報道）、NHK「再交付申請相次ぐ “効果は限定的”か」

これから身分証を出すときの注意

  • コピーや画像を求められたら、理由と保存期間を聞く。本当に必要か、何年保存するのか、退会したら消すのかを確かめます。
  • 住所の確認だけが目的なら、不要な部分を隠せないか聞く。免許証番号などを隠して出せる場合があります。
  • メールやアップロードで画像を送るなら、提出先と日付を書き込む。例：「〇〇社 提出用 2026年10月」。流出した画像の使い回しが難しくなり、漏れた元も分かります。アプリのカメラで撮る方式では使えません。
  • 選べるなら、マイナンバーカードの公的個人認証（電子証明書）を使う。顔写真の画像を相手に渡さずに済み、偽造にも強い方式です。暗証番号は誰にも教えないでください。
